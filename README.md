# Abdurahman Usman — portfolio (v12)

React + Vite + Tailwind. One-screen views: Home, About, Projects, Services, Contact.

## Setup
1. Put your own files in `public/` (they are not in the zip):
   - `profile-pic-9.png`, `hero-bg-3.jpg`
   - `projects/*.webp` screenshots and `projects/quizana-school.pdf`, `quizana-university.pdf`, `rose-oils.pdf`
2. Copy `.env.example` to `.env` and set the three `VITE_EMAILJS_*` values (also set them in your host's environment settings — Vite bakes them in at build time).
3. `npm install` then `npm run dev` / `npm run build`.

## Before publishing
- Add an `og:image` and `og:url` to `index.html` once you know your domain.
- Check what contact details you want public.
